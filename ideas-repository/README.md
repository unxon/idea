# Opportunity Repository

## Research synthesis

The inputs indicate a shift from isolated generation toward persistent, autonomous, and tool-using software workflows. The highest-value gaps are reliability, state management, verification, privacy, security operations, and domain-specific execution.

## Prioritization method

Ideas were prioritized using four dimensions: novelty, feasibility, potential impact, and implementation effort. Scores are directional assessments based only on the supplied inputs. Engagement counts and launch visibility are demand signals, not proof of willingness to pay.

## Recommended sequencing

1. Validate scenario-based agent testing with a narrow application and measurable regression outcomes.
2. Prototype persistent coding-agent memory with explicit versioning and rollback.
3. Test durable execution under interruption, budget limits, and tool failure.
4. Validate evidence tracing in one technical research domain.
5. Test small-business security workflows in read-only mode before offering remediation.

## Cross-cutting requirements

All agent-facing products should include permission boundaries, audit logs, human approval for consequential actions, failure recovery, cost controls, and evaluation datasets. Privacy-sensitive products should default to data minimization and make external transmission visible.
